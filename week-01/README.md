## Overview

This directory contains my Week 01 internship assignments, practical implementations, experiments, and technical documentation completed during my NetworkWalks internship.

The focus of this week was on virtualization, operating system installation, network configuration, IP addressing, connectivity testing, and troubleshooting.

Each project includes its implementation steps, commands, configuration details, troubleshooting process, and supporting screenshots.

## Week 01 Projects

**Project:** [WK1-PMx – How to Setup Android-x86 in VirtualBox](./WK1-PMx%20-%20How%20to%20setup%20Android-x86%20in%20VirtualBox/)

**Topics Covered:**
- Android-x86 installation in Oracle VirtualBox.
- NAT Network configuration.

- Static IP configuration.
- Routing and DNS troubleshooting.
- ICMP and ARP investigation.

## Weekly Learning Outcomes

During Week 01, I gained practical experience in:

- Creating and managing virtual machines using Oracle VirtualBox.
- Installing and configuring different operating systems.
- Understanding NAT Network configuration and virtual network communication.
- Assigning static IPv4 addresses and configuring network gateways.
- Understanding DNS configuration and network connectivity.
- Using Linux and Windows networking commands.
- Performing connectivity tests using ICMP and ping.
- Investigating and troubleshooting network communication failures.
- Configuring Windows Defender Firewall inbound rules.
- Documenting technical implementations with screenshots and detailed explanations.

The practical assignments helped me understand how virtual machines communicate over a shared network and how to identify and resolve common networking issues.
